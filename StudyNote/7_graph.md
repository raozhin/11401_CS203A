# 圖形 (Graph)

## 1. 核心定義 (Definition)

圖形 (Graph) 是一種由 **頂點 (Vertices, Nodes)** 與 **邊 (Edges)** 組成的資料結構，用來模擬物件之間的關係。
數學表示法： $G = (V, E)$，其中 $V$ 是頂點集合， $E$ 是邊的集合。

* **應用範例**：Google 地圖 (地點與路徑)、社交網絡 (人與朋友關係)、網際網路 (網頁與超連結)、柯尼斯堡七橋問題 (Euler Path 的起源)。

### 關鍵分類 
* **有向圖 (Directed Graph / Digraph)**：邊具有方向性 ($A \to B$)，例如網頁連結。
* **無向圖 (Undirected Graph)**：邊沒有方向性 ($A - B$ 代表 $A$ 與 $B$ 互通)，例如雙向道路。
* **加權圖 (Weighted Graph)**：邊具有權重 (Weight/Cost)，例如路徑距離或傳輸成本。



---

## 2. 重要術語 (Terminology)

掌握以下術語有助於理解圖形演算法 ：

* **Adjacent (相鄰)**：若兩個頂點之間有邊相連，則稱它們相鄰。
* **Path (路徑)**：從起點到終點經過的頂點序列。
* **Cycle (迴圈)**：起點與終點相同的路徑。
* **Connected (連通)**：若圖中任意兩點皆有路徑相通，則稱為連通圖。
* **Degree (度數)**：連接該頂點的邊數。
    * **In-degree (入度)**：指向該頂點的邊數 (有向圖)。
    * **Out-degree (出度)**：從該頂點指出的邊數 (有向圖)。

---

## 3. 圖的表示法 (Representation)

如何在程式中儲存圖形？主要有兩種方式 ：

### 3.1 相鄰矩陣 (Adjacency Matrix)
使用一個二維陣列 `matrix[V][V]`。若頂點 $i$ 與 $j$ 有邊，則 `matrix[i][j] = 1` (或權重)；否則為 0 。

* **優點**：檢查任意兩點是否有邊只需 $O(1)$。
* **缺點**：空間複雜度 $O(V^2)$，對於**稀疏圖 (Sparse Graph)** 非常浪費空間。

### 3.2 相鄰串列 (Adjacency List)
使用陣列搭配鏈結串列 (或 Vector)。陣列的每個索引代表一個頂點，該位置儲存一個串列，列出所有與其相鄰的頂點。

* **優點**：空間複雜度 $O(V + E)$，節省空間，適合稀疏圖。
* **缺點**：檢查兩點是否有邊需遍歷該點的串列，最壞 $O(V)$。

## 4. 圖的走訪 (Graph Traversal)

遍歷圖中所有頂點的方法，與樹的走訪類似，但需注意**避免重複訪問** (使用 `visited` 陣列) 。

### 4.1 廣度優先搜尋 (BFS) - 使用 Queue 
* **策略**：像水波擴散一樣，先訪問離起點最近的所有鄰居，再往下一層訪問。
* **特性**：保證在**無權重圖**中找到**最短路徑**。
* **實作**：使用 FIFO 佇列。

### 4.2 深度優先搜尋 (DFS) - 使用 Stack (或遞迴)
* **策略**：一條路走到黑，直到無路可走才回溯 (Backtrack)。
* **特性**：適合用於**偵測迴圈 (Cycle Detection)**、**拓撲排序 (Topological Sort)**、迷宮生成。
* **實作**：使用 LIFO 堆疊或遞迴。

---

## 5. 複雜度分析 (Complexity Analysis)

令 $V$ 為頂點數， $E$ 為邊數 。

| 操作 | 相鄰矩陣 (Matrix) | 相鄰串列 (List) |
| :--- | :---: | :---: |
| **空間複雜度** | $O(V^2)$ | $O(V + E)$ |
| **新增邊** | $O(1)$ | $O(1)$ |
| **移除邊** | $O(1)$ | $O(Degree)$ |
| **檢查相鄰 (Query)** | $O(1)$ | $O(Degree)$ |
| **BFS/DFS 走訪** | $O(V^2)$ | $O(V + E)$ |

---

## 6. 應用場景 (Applications) 

1.  **最短路徑**：GPS 導航 (Dijkstra, A* 演算法)。
2.  **社交網絡**：朋友推薦 (BFS 尋找二度人脈)。
3.  **網路爬蟲**：DFS/BFS 抓取網頁連結。
4.  **相依性解析**：編譯器解析檔案依賴順序 (拓撲排序)。
5.  **最小生成樹 (MST)**：鋪設電纜或網路線的最低成本路徑 (Prim's, Kruskal's)。
